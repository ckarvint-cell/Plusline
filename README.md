# PLUSLINE local design preview

Homepage and project detail preview using original supplied photos. Static HTML, CSS and JavaScript; no external font or script dependencies.

## Run

Serve `dist` with a local HTTP server on port 5000, for example `python -m http.server 5000 --bind 127.0.0.1 --directory dist`, then open http://localhost:5000.

## Current scope

- Responsive homepage: about, portfolio, services, Bucku usage note, contact.
- Five project detail views; Yama Resort includes construction and detail imagery.
- Mobile navigation, service accordions and project links.
- Instagram is the available contact channel. No inquiry form pretends to submit.
- Homepage hero uses `Foto/Yama Resort/43.png`; originals preserved.
- Supabase, Next.js integration, admin editing, PDF output and Vercel deployment remain future work. No deployment performed.
- Descriptions, service scope per project and project metadata should be reviewed by PLUSLINE before publication.
